## 🚀 Featured Projects

### [Matchmind](https://github.com/amanpal07/Matchmind)
An international football match prediction app built with historical results, a custom Elo rating system, Logistic Regression, and XGBoost. It presents home-win, draw, and away-win probability estimates alongside Elo rankings and model comparisons.

[↗ Live application](https://footballmatchmind.streamlit.app/) · [Source code](https://github.com/amanpal07/Matchmind)

### [Spendly](https://github.com/amanpal07/spendly)
A minimalist personal expense tracker built with Flask and SQLite. Includes authentication, expense management, category tracking, date filters, and a dashboard for reviewing spending.

[↗ Live demo](https://expense-tracker-production-ed4c.up.railway.app/) · [Source code](https://github.com/amanpal07/spendly)

### [Trek Buddy](https://github.com/amanpal07/trek-buddy)
A role-based trekking management application for administrators, trek staff, and trekkers. Built with Flask, SQLite, Bootstrap 5, and Flask-Login, with trek management and a booking workflow.

[View repository](https://github.com/amanpal07/trek-buddy)

### [100 Days of Machine Learning](https://github.com/amanpal07/100-days-of-machine-learning)
A hands-on learning repository covering machine learning concepts through practical notebooks, including data preparation, feature engineering, regression, classification, dimensionality reduction, and ensemble methods.

[Explore the learning log](https://github.com/amanpal07/100-days-of-machine-learning)

### [JPMorgan Chase · Midas (Forage)](https://github.com/amanpal07/forage-midas)
A repository associated with the JPMorgan Chase Advanced Software Engineering Forage programme.
